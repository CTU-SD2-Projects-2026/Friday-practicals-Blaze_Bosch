# C# GUI Student Management System

This project implements the Practical – 01 October 2026 requirements as a C# Windows Forms application.

## Requirements implemented

1. Login Screen
   - Username: `admin`
   - Password: `1234`
   - Correct credentials open the Dashboard.
   - Incorrect credentials show an error message.

2. Dashboard
   - Welcome message
   - Student Details
   - Student Summary
   - Logout

3. Student Details
   - Student Name
   - Student Number
   - Course
   - Age
   - Save confirmation
   - Back to Dashboard

4. Student Summary
   - Student Name
   - Student Number
   - Course
   - Age
   - Back to Dashboard

5. Navigation and functionality
   - Four connected forms
   - Working button events
   - Login validation
   - Named controls
   - Consistent GUI

## Run

Open `StudentManagementSystem.sln` in Visual Studio 2022 with a recent .NET 8 SDK installed.

Press `F5`.

No database is required.
